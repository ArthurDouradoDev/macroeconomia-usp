# Imagens dos Setores

Coloque aqui as imagens para cada setor. Se o arquivo existir, ele aparece no lugar do ícone; se não existir, o ícone padrão é exibido automaticamente.

## Arquivos esperados

| Arquivo | Setor | Onde aparece |
|---|---|---|
| `familias.png` | Famílias | Card de seleção de setor |
| `empresas.png` | Empresas | Card de seleção de setor |
| `governo.png` | Governo | Card de seleção de setor |

## Especificações recomendadas

- Formato: PNG com fundo transparente
- Tamanho: 96×96 px (mínimo), até 192×192 px para telas retina
- Estilo: ícone ou ilustração simples, com boa legibilidade em fundo escuro
